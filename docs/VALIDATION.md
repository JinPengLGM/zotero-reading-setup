# 共享版验证记录

日期：2026-11-17。平台：Windows。阅读功能原有基线为 Zotero 10.0.7，新增预设验证时本机 Zotero 为 10.0.8。

## 安装文件准备

- 从官方发布地址实际下载并验证 LLM 3.9.17、Translate 2.4.8、Better Notes 3.3.5；Style 从固定上游提交下载 6.0.110。四个文件的 SHA256 均与本机安装版本一致。
- 使用系统 Windows PowerShell 5 构建 XPI；完整准备与离线缓存重跑通过。
- 从 Git 导出的干净源码单独构建，包根目录包含 manifest、bootstrap、预设、样式及许可证；不依赖作者的 Downloads 目录或个人资料目录。

## 回归测试

六个测试文件全部通过：代码阅读的编码与转义/内容保真、Codex 失效路径修复、边缘行号识别、预设备份与恢复、流式协议/分段，以及翻译取消/缓存/重复任务/错误状态。

## Zotero 原生验证

实际从生成的 XPI 的 `jar:` 路径加载共享预设模块。使用真实的 Gecko 文件读取、Zotero 主窗口和原生菜单，设置读写替换为隔离的内存存储。

以下 8 项均通过：配置可从 XPI 读取、主窗口样式注入、CSS 范围限制到阅读器、原生预设菜单创建、预设应用、原设置恢复、停用后移除测试样式、停用后移除测试菜单。

该测试发现并修复了直接将 `jar:` 字符串交给 Zotero.File 的兼容问题；共享版通过 Gecko channel 读取打包资源。

## 范围说明

旧版的选文/批注、Python/C++ 创建与阅读、原生复制去行号已在原机器上做过实际交互验证。本次没有在另一台全新电脑上重做全部账号登录与服务请求，也没有测试其他操作系统或 Zotero 主版本。Codex 与翻译服务的连通性、模型权限和额度需要每位使用者用自己的账号完成安装后的检查。

发布材料经过个人路径、私有网关、已配置密钥与凭据的本地匹配检查；个人资料目录、文献和量化学习计划没有纳入版本控制。
